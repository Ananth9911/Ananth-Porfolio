> lineage_engine.dag

MetaLens · data lineage, impact analysis & AI catalog
Click any dataset — green = upstream (feeds it) · amber = downstream (impact)

Graph Engine

Dependency-free. DFS transitive lineage, BFS shortest-path, Kahn's topological build-order, and DFS cycle detection — all O(V+E).

Impact Analysis

"What breaks if this changes?" Computes the full downstream blast radius, grouped by governance layer.

RAG Q&A

Ask in plain English. Embeds the catalog, retrieves by cosine similarity, and grounds the LLM answer with citations.

SQL → Lineage

Paste SQL; an LLM infers column-level lineage, and a validator rejects any hallucinated references before they enter the graph.

LLM output is treated as untrusted — every inferred lineage edge is validated against the known catalog and hallucinated references are rejected before they reach the graph. Embeddings load on a background thread so the container answers its health probe instantly, with a dependency-free hashing fallback if the neural model is unavailable.

stack: FastAPI · Python 3.12 · Docker · Azure App Service · Azure Container Registry · GitHub Actions (OIDC) · Groq
